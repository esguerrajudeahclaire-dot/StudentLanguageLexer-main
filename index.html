    Student Record Language rules

    STUDENT <name> ID <number> COURSE <course> YEAR <number> SECTION <section> SUBJECT <subject> GRADE <number> STATUS <status> EMAIL <email> AGE <number>

    Keywords: STUDENT, ID, COURSE, YEAR, SECTION, SUBJECT, GRADE, STATUS, EMAIL, AGE.

    Alphabetic data is a VALUE; mixed letter/digit or underscore names are IDENTIFIER tokens. Numbers contain digits only. The record fields must appear in the listed order.

    DFA / Automata Theory

    A DFA reads characters through states: START → IDENTIFIER for a letter or underscore, then loops on letters, digits, or underscores; START → NUMBER on a digit, then loops on digits. Reaching the end in an accepting state recognizes that token.

    This illustrates the finite-state idea behind token patterns. The JavaScript lexer scans input and applies regular expressions; it does not execute a mathematical DFA.
